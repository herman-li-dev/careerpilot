# CareerPilot synthetic resume review guide

This public synthetic guide is intentionally limited to truthful clarification of existing resume evidence.

## SKILLS: Skill context
If accurate, clarify how an existing skill was used without adding unverified tools, metrics, outcomes, or responsibilities.

## PROJECTS: Project context
If accurate, add concise context to an existing project statement without inventing scope, results, tools, or responsibilities.

## EXPERIENCE: Experience context
If accurate, make the context of existing experience easier to assess without adding unverified achievements or responsibilities.

## EDUCATION: Education context
If accurate, make existing education evidence concise and clear without adding unverified credentials or results.
